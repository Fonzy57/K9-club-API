# 🐾 K9 Club API

K9 Club API is a RESTful web service developed in Java using Spring Boot.  
It is the backend part of a full-stack application designed as a capstone project for a software engineering training
program.

## 🎯 Project Purpose

The main goal of this project is to manage a canine club's activities and members through a dedicated API.  
It is part of a broader educational initiative and will evolve over time to integrate more features and secure access.

## 🧰 Tech Stack

- **Backend:** Java 17, Spring Boot
- **Database:** MySQL
- **Frontend:** Angular 19 (in a separate repository)

👉 Frontend GitHub repository: *coming soon*

## 📦 Features

- RESTful API structure
- Modular package organization (`controller`, `model`, etc.)
- Database connection with MySQL
- JWT authentication *(coming soon)*
